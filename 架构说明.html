三种角色，各看到什么

👤 普通观众

  • 打开 index.html
  • 看预言卡片和彩池进度条
  • 选 A 或 B，输入筹码下注
  • 看自己的历史记录和盈亏
  • 看到实时更新（SSE 推送）

🎙️ 主播/管理员

  • 打开 admin.html
  • 创建预言（标题、A/B选项、倒计时）
  • 提前封盘
  • 选 A 或 B 作为正确答案
  • 作废预言（全额退钱）
  • 置顶重要预言

⚙️ 系统/后厨

  • server.js 一直在后台跑
  • 检查你有没有登录、钱够不够
  • 下注时冻结你的筹码
  • 结算时按公式自动分钱
  • 广播"彩池变了"给所有人
  • 每笔钱变动都记流水

为什么必须启动服务器？直接打开 HTML 不行吗？

❌ 直接双击 index.html（file:// 打开）

你能看到漂亮的界面、按钮、进度条——但它们是"死"的。一点下注，JS 去请求 /api/predictions，浏览器直接报错：没有服务器在听。数据永远是空的，登录不了，下不了注。

✅ npm start 后访问 localhost:3000

server.js 启动后同时干两件事：① 把 public/ 下的 HTML/CSS/JS 发给浏览器（这是"静态"部分）；② 监听 /api/* 请求，查数据库、算钱、返回 JSON（这是"动态"部分）。两者缺一不可。

每个文件的职责

yuyan/ ├── package.json # 清单：装哪些依赖 ├── server.js # ★ 后厨：所有 API + 业务逻辑 ├── db.js # 建表：users / predictions / bets / chip_logs ├── seed.js # 初始化管理员账号 ├── lib/ │ ├── settlement.js # 结算公式 floor(失败池×你的钱/胜方池) │ └── sse.js # 广播喇叭：维护在线连接，推消息 ├── public/ # 浏览器拿到的"菜单" │ ├── index.html # 观众端页面 │ ├── admin.html # 管理后台 │ ├── css/style.css # 样式：颜色、布局、手机适配 │ └── js/api.js # 前端工具：fetch封装、登录态、SSE连接 ├── test/smoke.js # 1000轮自动测试脚本 └── data/yuyan.db # SQLite账本（自动生成）
